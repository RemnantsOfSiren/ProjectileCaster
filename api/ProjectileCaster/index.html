ProjectileCaster

ProjectileCaster is a class that allows you to cast projectiles in the game world, and handle the logic of the projectile's movement and collision. Projectile detection is both client and server sided, and can be configured to ignore specific instances. It utilizes a loose sanity check to ensure that the projectile is not being abused by the client.
