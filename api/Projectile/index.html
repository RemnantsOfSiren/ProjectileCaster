UpdateDirection​

</>
Projectile:UpdateDirection(Direction: Vector3) → ()

Starts a new trajectory segment from wherever the projectile is right now. This is the only thing that puts an update on the wire.

Called from a Hit handler it instead rebases to the exact point and moment of contact, so a deflection does not depend on which sub-frame phase the projectile happened to be cast on. Two identical shots into identical geometry then leave in identical directions.

Destroy​

</>
Projectile:Destroy() → ()

Destroys the projectile. this method will destroy the projectile and all of its connections. It's auto called if there is a max distance specified and the projectile reaches it.
